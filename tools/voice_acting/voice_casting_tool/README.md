# Voice Casting Tool

Local web app for browsing ElevenLabs voices and assigning them to NPCs in
Ultima VII: The Black Gate. Part of the Exult voice acting pipeline (see the
[parent README](../README.md) for the big picture).

## What it does

- **NPC grid.** All speaking NPCs from the manifest, grouped by city, with
  pixel art portraits, voice assignment status, and completion tracking.
  Filters for unvoiced NPCs and specific towns are URL-driven so bookmarks
  and browser history work.
- **NPC detail.** Per-character page with wiki infobox, dialog lines, voice
  assignment, and "Forge Voice" for generating test samples. If a generated
  WAV already exists on disk (at `VOICE_WAV_DIR`), a play button appears to
  audition real lines.
- **Voice library search.** ElevenLabs shared voice library with filters for
  gender, age, accent, language, use case, and descriptive. Accent dropdown
  groups Western European accents at the top. "My Voices" panel surfaces your
  own cloned voices from the ElevenLabs account.
- **AI suggestions.** Each NPC has a suggested voice profile generated by
  Claude based on their wiki entry, city, and dialog samples. One-click to
  apply the suggested filters to the search.
- **Bookmarks.** Save interesting voices while browsing. Assign later.
- **Ledger.** Voice assignments grouped by city, with progress bars.
- **Export CSV.** Download the canonical NPC-to-voice map for use by
  `prepare_voice_lines.py`.

## Prerequisites

- Node.js 18+
- An [ElevenLabs](https://elevenlabs.io) API key
- Python 3.10+ for the companion scripts in `scripts/`
- An [Anthropic](https://console.anthropic.com) API key for
  `scripts/suggest_voices.py` (optional)

## Setup

From the voice_acting directory (not this one):

```bash
cd tools/voice_acting/voice_casting_tool
npm install
```

The app reads configuration from `../.env` (the voice_acting-level `.env`).
Set at minimum:

```
ELEVENLABS_API_KEY=sk_...
# Optional - paths default to sensible values if unset:
MANIFEST_CSV=/absolute/path/to/csvs/manifest.csv
VOICE_WAV_DIR=/absolute/path/to/patch/voice_acting
ANTHROPIC_API_KEY=sk-ant-...
```

When `VOICE_WAV_DIR` is unset, the "play from disk" feature is disabled and
the app works in ElevenLabs-preview-only mode — useful when sharing the app
with someone who doesn't have the generated audio locally.

## Running

```bash
npm run dev
```

Starts the Express backend on port 3001 and the Vite dev server on 5173.
Open http://localhost:5173.

## Companion scripts

All runnable from the voice_acting directory:

```bash
# Build/refresh wiki page URLs for each NPC (MediaWiki API probing)
python voice_casting_tool/scripts/resolve_wiki_urls.py

# Download each resolved wiki page as JSON (summary + infobox)
python voice_casting_tool/scripts/fetch_wiki_pages.py

# Scan the ElevenLabs voice library and record observed filter values
python voice_casting_tool/scripts/discover_voice_filters.py

# Ask Claude to suggest voice filters for every NPC
python voice_casting_tool/scripts/suggest_voices.py
```

Each script is idempotent; their outputs live in `data/wiki_data/`.

## Typical workflow

1. Open the app and pick an NPC from the grid.
2. Review the wiki infobox and dialog lines.
3. Look at the AI-suggested filters in the Voice Library panel. Click
   **Apply** to load them into the search, or edit them as needed.
4. Preview candidates (ElevenLabs preview, or click the disk-play button to
   hear a pre-generated line in the candidate voice if it exists).
5. Click **Assign** on your pick. Your choice goes into
   `data/casting.db`.
6. When done, click **Export CSV** in the header. Save the file at
   `../voice_assignments.csv` and commit it — that's the source of truth for
   the generation pipeline.

## Exporting for generation

The **Export CSV** button in the header downloads a timestamped file:

```
npc_name,city,voice_id,voice_name,preview_url,assigned_at
Abraham,Endgame,agL69Vji082CshT65Tcy,"Blackwood - Sinister, Posh and British",...
```

Save it as `tools/voice_acting/voice_assignments.csv` to update the committed
voice map. `prepare_voice_lines.py --voice-map voice_assignments.csv` reads
it directly.

## Backing up the database

`data/casting.db` holds all assignments, bookmarks, and generated-sample
metadata. To snapshot:

```bash
cp data/casting.db "backups/casting-$(date +%Y%m%d-%H%M%S).db"
```

The `backups/` directory is gitignored.
