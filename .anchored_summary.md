## Key Decisions
- `voice_prompt` = design.`voice_desc_en`; add `voice_prompt_zh` = design.`voice_desc_zh`. `tone`/`tone_instruct` remain metadata (Base clone model has no text-instruct param).
- Speedup = native model batching (one call per bucket of same prompt+length) + multi-GPU via language sharding (1.7B model fits both GPUs).
- `generate_single_part_batch` passes `voice_clone_prompt=prompt` (a length-1 list of `VoiceClonePromptItem`); the model broadcasts it to the batch — it must NOT wrap the prompt or pass `ref_audio` (the model rejects that).
- Orchestrator must point at `generate_qwen3_voice.py` (not itself) and pass `--device cuda:0` because `CUDA_VISIBLE_DEVICES` remaps the isolated GPU.
- Reference audio (`tools/voice_acting/refs/`, 922 files) unchanged by Task 1, so clone prompts did not need rebuilding for this regen.
